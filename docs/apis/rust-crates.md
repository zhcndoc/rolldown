# Rust Crates

Rolldown 也作为一个 Rust crate 提供在 crates.io 上。

主 crate 是 [rolldown](https://crates.io/crates/rolldown) crate。

## 维护策略

在使用这些 crates 之前，请务必了解以下策略：

- 这些 crates 不会遵循 semver 合约。任何版本中都可能自由引入破坏性变更。
- 不会提供这些 crates 的文档。
- 任何仅影响 Rust crates 的问题都不会作为团队工作来处理，并且会被关闭。不过，我们会接受针对这些用例的 pull request。

JS 包是我们的重点，我们希望尽可能降低 crates 的维护成本。如果有一位长期贡献者愿意承担这部分的维护工作，我们愿意重新审视后两项策略。
